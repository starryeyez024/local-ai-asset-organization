About

AI Assets Explorer is a snapshot of the skills in a configured directory. Browse Skills searches and filters every valid SKILL.md found there. Audit Skills shows the local entries, broken links, duplicate names, and file age. Neither view installs, edits, or runs a skill.

Where the data comes from

generate-skills-json.py scans ~/.agents/skills by default. It accepts symlinks and real directories. Set SKILLS_ROOT to scan another directory. It reads skill frontmatter and selected Markdown sections, then uses fixed keyword rules to assign tags. The source SKILL.md files remain authoritative.

Shareable catalog: skills.json contains the Browse Skills data and can be committed or published.

Local audit: skills-local.json also contains absolute paths and inventory details. It is ignored by Git and must stay on the machine that generated it. Without this file, the page hides Audit Skills.

How tags work

Tool, task, phase, and stage tags are keyword guesses based on each skill's name, description, and the start of its body. A skill can match several tool, task, or stage tags. Phase uses a priority order and defaults to “In Progress.” Role is inferred from a known AI-first module path; other sources use “Other.” Skill type comes from frontmatter when available, otherwise a name beginning with workflow- is treated as a workflow.

If a tag is misleading, update the keyword rules in generate-skills-json.py and regenerate the files. There is no tag editor in the page. A file older than 60 days is marked “Stale” in the local audit as an age cue, not proof that the skill is obsolete.

Refresh and preview

cd /path/to/local-ai-asset-organization/skills-explorer
make run
# open http://localhost:8790

make run runs make regen and starts the local server. Run make regen alone to update the data or make serve to preview an existing snapshot. Use PORT=8080 make serve for another port.

SKILLS_ROOT=/another/skills/directory make regen

After a source skill changes, regenerate and review the catalog. Commit the skill in its source repository and the shareable skills.json in this repository. Do not commit skills-local.json. The local file manager action is available only when using the preview server. This project has no scheduled rebuild; published data reflects the last committed snapshot.

Requires Python 3.10+ and Make. The generator uses only Python's standard library.
