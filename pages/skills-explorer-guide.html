What it is

Search your catalog

The Explorer reads skills.json and a private scripts-local.json to show searchable names, descriptions, and sources. Choose Skills or Scripts under Asset Type. In the separate Automation group, uncheck Manual to see scripts with a directly matched job, or uncheck Automated to see scripts with no matched job. Expanded script cards show cron or launchd details. Work Stage, Tool, and Task Type categorize both skills and scripts; Skill Maturity applies to skills. Source files stay in their owning repositories.

Browse

Search by name or description to find a relevant skill or registered script.

Filter by source

Use the Source repository filter to narrow the catalog to labels such as ixd-firefly or tailwind.

Inspect schedules

Script cards list directly matched job labels and schedules. A definition match does not prove the job is loaded or runs successfully.

Source files

Keep changes in the owning source

The assistant reads each resolved SKILL.md, the private script catalog, and local job definitions to build your view. Guided setup saves the result in ~/.local/share/ai-assets-explorer/. The skills-local.json and scripts-local.json files contain absolute paths and stay on your machine. If an entry looks wrong, check its source and refresh the Explorer.

Guided setup

Ask your assistant to open your Explorer

The agent-setup workflow prepares the Explorer after organizing your assets. It uses your skills folder and private script catalog, builds the local data, and opens the viewer. You don’t need to choose a data folder or run the generators yourself.

Already set up? Ask “Open my AI Asset Explorer” or “Refresh my asset catalog.” Your assistant uses the setup notes to find your catalog and start it again.

Your assistant checks existing configuration, known skills folders, and script registrations before choosing the local catalog sources.

Keep it current

Refresh after changing assets or jobs

Ask your assistant to refresh the catalog after changing a skill, script registration, or job definition. Marketplace packages stay under their installer’s control.

Browse Assets helps you find an entry. Audit Skills shows issues in the configured skills folder, such as broken links. Opening a card does not run a skill or script.

Boundaries

What the assistant handles alongside the Explorer

Catalog coverage: the generator scans one configured skill directory. The setup assistant checks marketplace registries, other tools’ folders, and runtime enablement separately. A marketplace skill missing from the catalog may be installed elsewhere; its managed files stay with the installer.

Agent discovery

The assistant checks how your chosen tool discovers skills and verifies that it can find them. The compatibility matrix explains the paths and runtime constraints behind those checks.

Installation

Ask your setup assistant to make a selected skill available in the tool you use. It handles the installation or linking; the Explorer provides the catalog.

Skill maintenance

The assistant updates descriptions and procedures in the source skill’s tracked folder, then refreshes the catalog. The Explorer displays those changes.

Running a skill

Opening a card does not run its scripts. The local source-file button asks the preview server to show an inventoried file in your file manager. Use your configured agent or tool to review and run the skill.
