Quick reference

For the full workflow, ask your assistant to read agent-setup and guide you in one conversation. For one stage, pick the step you need below.

  1. Inspect or create local AI configuration — agent-setup.
  2. Build or update personal context — context interview.
  3. Audit your assets — ai-asset-auditor.
  4. Add skill symlinks — skill-linker.
  5. View your skills and registered scripts — open the Explorer, or ask “Open my AI Asset Explorer.”
  6. Refresh your catalog — ask “Refresh my asset catalog.” Setup and refresh instructions.
  7. Customize a shared skill — skill-override-safeguard.
  8. Check tool support — compatibility chart.

Local script lookup

These examples use the auditor helper in this checkout. Python 3.11 or newer is required. Inventory can run before you create a catalog; validation and lookup use your private configuration.

python3 skills/ai-asset-auditor/scripts/script-catalog.py inventory --root example-tools=/path/to/checkout
python3 skills/ai-asset-auditor/scripts/script-catalog.py validate
python3 skills/ai-asset-auditor/scripts/script-catalog.py --json resolve example-tools/hello

In native Windows PowerShell, replace python3 with py -3 and use a Windows path for the root. Add --config PATH before the operation for a custom setup file. Catalog format and error rules.
